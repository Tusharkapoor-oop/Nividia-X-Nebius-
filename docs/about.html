About this site

A static rendering of the run evidence committed in this repository. There is no server, no database, and no JavaScript: upgradepilot site build reads the artifact JSON files and writes these pages.

What a recorded run is

Each page corresponds to one result file: an agent upgrade report (artifacts/runs/), a Phase 5 strategy result (artifacts/phase5/), or a demo-case result (artifacts/demo/). Statuses, counts, tokens, and timestamps are copied from those files; the timestamp comes from the run id or the result file itself and the page says which.

Providers

Recorded providers on this build: NVIDIA NIM. Runs are labelled with the provider that produced them. An NVIDIA NIM run is a development run and is never presented as a Nebius Token Factory run.

Run it locally

git clone <repository>
cd upgradepilot
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e ".[web,dev]"
copy .env.example .env   # add keys
upgradepilot doctor
upgradepilot upgrade <repo> --package <name> --to <version>

Honest limits

  • The hosted site shows recorded runs, not a live service.
  • An empty table means no result file exists; it never means "nothing failed".
  • Unreadable artifact files are listed on the home page rather than hidden.
